# البنية التقنية وخطة التنفيذ

## الفكرة الأساسية

**المحرك منفصل عن الواجهة.** كل قواعد المساعد (الخطة، القفل والفتح، توليد الاختبارات، التصحيح، تحديد المستوى، التحفيز، التقارير) موجودة في مكتبة TypeScript واحدة مفيهاش أي واجهة. بعد كده أي واجهة — تطبيق موبايل، موقع، بوت واتساب — بتستخدم نفس المحرك.

ليه TypeScript؟ نفس الكود يشتغل على السيرفر (Node.js) وفي تطبيق الموبايل (React Native) وفي الموقع (React/Next.js).

## الملفات

```
src/
├── config.ts                    ← كل الأرقام والقواعد في مكان واحد
├── curriculum/types.ts          ← شكل المنهج (فصول، دروس، نواتج تعلم، قاموس)
├── content/science-g4-term1/    ← محتوى Science رابعة ابتدائي (المنهج، التقويم، الأسئلة)
├── questions/                   ← أنواع الأسئلة + أدوات كتابتها + أسئلة تجريبية
├── planner/planner.ts           ← جدول الترم أسبوع بأسبوع
├── assessment/quiz.ts           ← توليد اختبار جديد كل مرة
├── assessment/grading.ts        ← التصحيح والدرجات الجزئية
├── mastery/mastery.ts           ← تحديد مستوى الطالب (Elo)
├── gamification/                ← النقاط والمستويات والأوسمة
├── journey/                     ← رحلة الطالب وقواعد التدرّج (قلب المساعد)
├── reports/                     ← تقارير ولي الأمر + طباعة الخطة
├── notifications/               ← إرسال الرسائل (طرفية دلوقتي، واتساب بعدين)
└── simulation/                  ← طالب افتراضي للتجربة
examples/simulate-term.ts        ← محاكاة ترم كامل
tests/                           ← 44 اختبار آلي
```

## إزاي الواجهة هتستخدم المحرك

```ts
const plan = buildStudyPlan(scienceG4Term1, term1Calendar2026);
const journey = StudentJourney.start(student, scienceG4Term1, plan, scienceG4Term1Bank, today);

journey.availableActions(today);           // ← المهام اللي تظهر للطالب النهارده
journey.completeLearning("ch1-l1", today); // ← خلّص الشرح
const quiz = journey.createQuiz({ type: "homework", lessonId: "ch1-l1", remediation: false }, today);
toStudentView(quiz);                       // ← اللي يتبعت للموبايل (من غير الإجابات)
const outcome = journey.submit(quiz, answers, today);
outcome.notifications;                     // ← رسايل ولي الأمر اللي لازم تتبعت
journey.state;                             // ← JSON واحد يتخزن في قاعدة البيانات
```

## البيانات

| الكيان | فين | ملاحظات |
|---|---|---|
| المنهج + بنك الأسئلة | ملفات في الكود دلوقتي | بعدين: لوحة تحكم للمحتوى + قاعدة بيانات |
| خطة الطالب | بتتحسب من المنهج + التقويم | مش محتاجة تتخزن |
| حالة الطالب `StudentState` | JSON واحد لكل طالب | فيه كل حاجة: الدروس، الاختبارات، المستوى، النقاط، سجل الأحداث |
| الاختبار المولّد | لازم يتخزن على السيرفر لحد ما الطالب يسلّم | الإجابات الصحيحة مابتوصلش للموبايل |

## خطة التنفيذ المقترحة

| المرحلة | المحتوى | الحالة |
|---|---|---|
| **0. الهيكل** | المحرك + المحاكاة + الاختبارات | ✅ خلصت |
| **0.5 المنهج** | الترم الأول كامل: 8 فصول، 26 درس، 989 سؤال | ✅ خلصت (محتاجة مراجعة مدرس) |
| **1. طريقة الشرح** | نتفق إزاي المساعد هيشرح: فيديو قصير؟ شرح تفاعلي خطوة بخطوة؟ معلم ذكي بالعربي المصري (Claude) بيشرح من الكتاب ويجاوب على أسئلة الطفل؟ | ⏭️ الخطوة الجاية |
| **2. محتوى أغنى** | صور للأسئلة (الرسومات والجداول من الكتاب)، أسئلة "قارن" و"بطاقة الملاحظة"، واختبار على كل فصل زي كتاب التقييمات | |
| **3. أول نسخة يجربها طفل** | تطبيق ويب يشتغل على الموبايل (PWA) للطالب + صفحة لولي الأمر + سيرفر وقاعدة بيانات | |
| **4. ولي الأمر** | إرسال التقارير على واتساب (WhatsApp Business API) | |
| **5. الذكاء الاصطناعي** | تصحيح "علل" و"ماذا يحدث لو" المكتوبة، وتوليد أسئلة جديدة من الكتاب بمراجعة بشرية | |
| **6. التوسع** | باقي المواد والصفوف — المحرك نفسه مش هيتغير، بس المحتوى | |

## تشغيل المشروع

```bash
npm install
npm test                                   # الاختبارات الآلية
npm run typecheck                          # فحص الأنواع
npm run simulate                           # محاكاة ترم لطالب متوسط
npm run simulate -- --ability=950          # طالب ضعيف (هتشوف المراجعة العلاجية والإعادة)
npm run simulate -- --ability=1250 --verbose  # طالب متفوق + كل الأحداث والرسايل
```
