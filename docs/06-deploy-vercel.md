# الرفع على Vercel للتجربة مع الطلاب

الموقع فيه صفحة الدروس، وكل درس جاهز بصوره وألعابه، و"اسأل المعلم" شغال من السيرفر بتاعك. الطالب بيفتح الرابط من موبايله على طول، من غير ما يسطّب حاجة.

## مرة واحدة: ربط المشروع

1. ادخل على [vercel.com](https://vercel.com) واعمل حساب بـ GitHub.
2. **Add New → Project**، واختار الريبو `minigenius2/AHMED2`. لو مش ظاهر، دوس **Adjust GitHub App Permissions** واسمح لـ Vercel يشوفه.
3. سيب الإعدادات زي ما هي (الملف `vercel.json` فيه أمر البناء). **Framework Preset** يفضل **Other**.
4. افتح **Environment Variables** وضيف:

   | الاسم | القيمة | لازم؟ |
   |---|---|---|
   | `ANTHROPIC_API_KEY` | مفتاح من [console.anthropic.com](https://console.anthropic.com) ← API Keys | أيوه، عشان "اسأل المعلم" |
   | `PILOT_CODE` | كود قصير بتديه للطلاب، زي `nabih2026` | مقترح جدًا |
   | `TUTOR_MODEL` | موديل تاني، زي `claude-haiku-5-5` (أرخص بكتير) | لأ |

5. دوس **Deploy**. بعد دقيقة هيطلعلك رابط زي `ahmed2.vercel.app`.

## الفرع اللي بيترفع

الشغل كله على الفرع `claude/elegant-heisenberg-nh9fyp`. Vercel بيعمل رابط تجريبي لكل فرع، بس **روابط الفروع بتبقى مقفولة على أصحاب حساب Vercel** (Deployment Protection)، فالطلاب مش هيعرفوا يفتحوها. عشان الرابط الأساسي (اللي مفتوح للكل) يبقى هو الشغل ده، اعمل حاجة من الاتنين:

- **Settings → Environments → Production → Branch Tracking**: غيّر الفرع لـ `claude/elegant-heisenberg-nh9fyp`.
- أو قولي وأنا أعمل Pull Request يدمج الشغل في `main`.

بعد كده أي تعديل بيترفع على الفرع بيتحدّث على الموقع لوحده.

## مع الطلاب

- ابعت لهم الرابط والكود. أول ما الطالب يسأل المعلم، الصفحة هتطلب الكود مرة واحدة وتحفظه على موبايله.
- تقدّم كل طالب (النقط، واللاصقات، والحصص اللي خلصها) متسجل **على موبايله بس**. لسه مفيش لوحة تجمّع نتايج كل الطلاب عندك، فملاحظات التجربة هتبقى منك ومن الأهالي. لو محتاجها، دي الخطوة اللي بعدها: قاعدة بيانات صغيرة على Vercel.
- "اسأل المعلم" عليه 10 أسئلة في اليوم لكل طالب، و30 سؤال في الساعة لكل جهاز على السيرفر.

## الفلوس

- Vercel: الخطة المجانية (Hobby) كفاية لتجربة مع كام طالب.
- "اسأل المعلم" بيتحاسب من رصيد Anthropic بتاعك (التقدير في [04-teaching.md](04-teaching.md)). **حط حد شهري للصرف** من console.anthropic.com ← Billing، عشان مايحصلش أي مفاجأة.

## لو حاجة مش شغالة

- **المعلم بيقول "مشغول" على طول**: افتح المشروع على Vercel ← **Logs**. لو مكتوب `ANTHROPIC_API_KEY is not set`، ضيف المفتاح. بعد أي تغيير في Environment Variables لازم **Redeploy** من صفحة Deployments.
- **الصور مش ظاهرة**: افتح رابط الدرس نفسه (`/lessons/ch1-l1/`) واتأكد إن البناء خلص من غير أخطاء في صفحة الـ Deployment.

## التجربة على جهازك قبل الرفع

```bash
npm run build:web     # بيبني الموقع في .vercel/output
npx vercel dev        # (اختياري) يشغّله زي Vercel بالظبط، محتاج تسجيل دخول Vercel
```
