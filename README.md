# مساعد الطالب الذكي 🎓

مساعد يذاكر مع الطالب طول الترم، عشان مايحتاجش دروس خصوصية. البداية: **Science — الصف الرابع الابتدائي (لغات) — الترم الأول 2026/2027**.

## المساعد بيعمل إيه؟

1. **يعمل خطة للترم كله** أسبوع بأسبوع، ماشية مع توزيع المدرسة، وفي آخرها أسبوعين مراجعة نهائية.
2. **في كل درس**: شرح ← واجب ← 3 اختبارات (🥉 أساسي، 🥈 متوسط، 🥇 للمتفوقين). كل محاولة اختبار جديد بأسئلة مختلفة.
3. **مفيش درس جديد** غير لما ينجح في الاختبار الأساسي للدرس اللي قبله. لو اتعثر، بيرجع يراجع ويحل واجب علاجي على نقط ضعفه.
4. **آخر كل أسبوع**: اختبار، ونتيجته بتتبعت لولي الأمر.
5. **كل شهر**: اختبار تراكمي على كل اللي فات، والشهر اللي بعده مقفول لحد ما ينجح.
6. **آخر المنهج**: تلخيص لكل فصل + امتحانات تجريبية.
7. **تحفيز زي الألعاب**: نقاط، مستويات، نجوم، أوسمة، وأيام متواصلة.
8. **يحدد مستوى الطالب بدقة** في كل جزئية من المنهج، ويقول لولي الأمر بالظبط هو ضعيف في إيه (حتى نوع السؤال: علل، ماذا يحدث لو...).

## الحالة دلوقتي

- ✅ المحرك كامل: الخطة، القفل والفتح، توليد الاختبارات، التصحيح، تحديد المستوى، التحفيز، تقارير ولي الأمر.
- ✅ **منهج الترم الأول كامل**: 8 فصول، 26 درس، **989 سؤال** بأشكال أسئلة الامتحان. كل درس فيه 10 أسئلة أو أكتر للمتفوقين، متألفة مننا.
- ✅ أسبوع كل درس مأخوذ من فهرس التقييمات الأسبوعية (11 تقييم)، والخطة ماشية مع توزيع الوزارة.
- ✅ **طريقة الشرح**: حصة تفاعلية بالعامية المصرية والمصطلحات بالإنجليزي، فيها أسئلة فهم وإعادة شرح ومراجعة علاجية، و"اسأل المعلم" (أستاذ نبيه 🦉) بحد يومي.
- ✅ أول درس مكتوب كامل (حصتين)، وله نسخة تجريبية تتفتح على الموبايل. كل شرح بيخلص بـ"كمّل الجملة"، والطفل مايعديش غير لما يجاوب صح.
- ✅ نص التسجيل لأول درس جاهز لمؤدي الصوت (`recording/ch1-l1.md`)، والنسخة التجريبية بتشغّل التسجيلات أول ما توصل.
- ⏭️ الخطوة الجاية: نختار مؤدي الصوت (تجربة 10 جمل)، ونكتب باقي الـ 25 درس بنفس القالب.

## التشغيل

```bash
npm install
npm test                                  # 58 اختبار آلي
npm run preview:lesson -- ch1-l1          # نسخة تجريبية للحصة تتفتح على الموبايل (preview/ch1-l1.html)
npm run voice:sheet -- --all              # نص التسجيل لمؤدي الصوت (recording/)
npm run simulate                          # محاكاة ترم كامل لطالب افتراضي
npm run simulate -- --ability=950         # طالب ضعيف: هتشوف المراجعة العلاجية وتنبيهات ولي الأمر
npm run simulate -- --ability=1250 --verbose
```
